# 中国象棋 · 好友房间

一个能直接打开就玩、还能发给朋友一起下棋的网页版中国象棋。纯前端，没有后端服务器。

## 在线玩

https://xiaoshixiansheng.github.io/chinese-chess-pwa/

## 三种玩法

| 模式 | 说明 |
| --- | --- |
| 人机对战 | 你执红先行，电脑执黑。棋力可选：入门 / 普通 / 稍强 |
| 两人同桌 | 同一台设备轮流走，红黑交替 |
| 好友房间 | 建房得 4 位房间号，好友输房间号或点邀请链接即进；你执红，对方执黑 |

## 规则实现

- 车、马（别马腿）、炮（炮架吃子）、相/象（塞象眼、不过河）、士（九宫）、将帅（九宫）、兵卒（过河横走）
- 将帅照面（飞将）判负
- 不允许走出「送将」的棋（走后自己被将军的着法直接过滤）
- 一方无合法着法判负（将死 / 困毙）
- 将军提示、上一步高亮、可落点提示、悔棋、认输

## 联机原理

好友房间用 WebRTC 点对点直连（PeerJS 公共信令 + STUN/TURN），走法只在两台浏览器之间传输，不落任何服务器。房主（执红）是权威端，新加入者会收到完整棋谱重放，断线重连也能对齐。

## PWA

浏览器里点「安装」即可装到桌面/手机，断网也能玩人机和同桌模式。

## 文件

- `index.html` 界面 + 对局逻辑 + 联机
- `engine.js` 规则引擎与 AI（negamax + alpha-beta）
- `peerjs.min.js` WebRTC 库（本地自带，不依赖 CDN）
- `service-worker.js` / `manifest.json` / `icons/` PWA 支持
